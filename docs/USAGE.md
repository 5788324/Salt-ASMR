# 使用、备份与 Windows 验收

## 导入作品

在 Salt 模组配置点击“打开作品收藏与歌单”，选择“导入 RJ 目录”。可选单部作品或小规模父目录。支持识别 MP3、WAV、FLAC、M4A、OGG、Opus 的文件扩展名，仅枚举名称与大小，不验证或解码音频内容。

目录名需含独立 RJ 编号，例如 `[RJ01234567] 作品名称`。无 RJ 编号的音频暂不导入。嵌套 RJ 目录归属最近的 RJ 父目录，不跟随目录内符号链接。

- 同一目录重复导入保留收藏与歌单，不产生新的作品 ID。
- 同一个 RJ 在不同目录下分别显示，目录路径可用于区分版本。
- 当前扫描为追加 / 更新，不自动删除历史音轨。文件缺失时保留记录。
- 目录移动后重新导入会形成新条目，当前不自动合并；不要依赖它自动迁移收藏。
- 取消扫描不提交扫描结果；权限读取失败时本次不导入，已有数据保留。
- 单次最多枚举 20,000 个音频；请先用 3 部作品测试，不要从磁盘根目录开始。

## 收藏与作品歌单

选中作品，点击“喜欢 / 取消喜欢”。顶部“查看”中选择“喜欢的作品”筛选。

“新建歌单”创建作品列表；选择作品后“加入歌单”。同一作品在同一歌单只出现一次。选择该歌单后可“移出歌单”、“上移”、“下移”，顺序立即保存。搜索过滤期间禁用顺序调整，清空搜索后操作。

删除歌单只删除列表和成员关系，不删除作品、喜欢、音频或字幕。当前不提供从资源库删除作品的入口。

这些是插件自己的作品歌单，不是音频播放队列；不替换 Salt 原生歌单，也没有“播放整个歌单”的按钮。使用“打开目录”定位原始文件，再通过 Salt 原生功能播放。

## 数据位置、备份与恢复

正式 Windows 数据目录：`%APPDATA%\Salt-ASMR`。

- `library.sqlite`：作品、音轨清单、喜欢和歌单。
- `library.sqlite-wal` / `library.sqlite-shm`：SQLite 可能生成的工作文件。
- `library.lock`：防止两个进程同时修改数据的锁文件，文件存在本身不表示锁仍被占用。

数据不放在插件安装目录。停用、更新、卸载不主动删除它。

点击“备份作品数据”，选择一个**尚不存在**的 `.sqlite` 文件。插件通过 SQLite 生成一致快照，不直接复制运行中的主数据库。备份含本地目录路径，不含音频内容。

恢复步骤：

1. 关闭作品窗口并停用插件；若仍有文件占用，完全退出 Salt。
2. 把当前整个 `Salt-ASMR` 数据目录复制到其他位置保留，不覆盖旧备份。
3. 在原位置创建新的空 `Salt-ASMR` 目录，将备份复制为 `library.sqlite`；不要带入原来的 WAL / SHM 文件。
4. 重新启用插件，核对作品、喜欢和歌单。音频目录未挂载时仍应看到记录。

数据库损坏或版本过高时插件拒绝打开，不自动清空重建。请保留故障文件并从备份恢复。

## 构建与独立窗口测试

JDK 25，Gradle Wrapper 已锁定 9.8.0 与分发校验值：

```powershell
.\gradlew.bat test plugin
.\gradlew.bat runDesktop
```

`runDesktop` 默认使用 `build/desktop-data`，属于独立预览，不是 Salt 宿主模拟。指定预览目录：

```powershell
.\gradlew.bat runDesktop -PdataDir=D:\SaltAsmrTestData
```

有图形显示时可执行 `test -Dsaltasmr.uiTest=true`，验证窗口收藏、筛选、歌单移除、排序和重新打开。Linux 无桌面时可使用 Xvfb。测试音频是枚举用的合成字节，不代表真实 MP3 / WAV 的播放验证。
