# Salt-ASMR

> 基于 Salt Player for Windows（SPW）Workshop 插件系统的本地 RJ / ASMR 音声专辑管理扩展。

**当前状态：P0 技术验证准备中。仅完成文档与公开源码研究；尚无插件实现、可安装的 .spmod 或 Windows 宿主实测结果。**

## 项目目标

- 将 RJ 视为完整作品，保留原版、翻译版、音效与编码等版本分支。
- 复用 Salt 的解码、音频输出和原生歌词能力，集中开发作品整理与收听体验。
- Windows 优先、中文界面、本地优先；默认不移动、不改名、不修改原始音频与标签。
- 不捆绑 AI 模型，通过本地字幕文件对接外部 ASR / 翻译结果。

## 当前技术判断

**有条件继续，只推进播放 P0；验证通过后再开发完整作品库 UI。**

截至 2026-11-17，已核对官方 API 默认分支与发布版 `0.1.0-dev23` 的关键接口源码。dev23 已发布；默认分支版本配置仍标注 dev22，两者不可混同。关键接口的内容核对结果及来源见 [技术评审记录](docs/TECHNICAL_REVIEW.md)。

| 能力 | 已核实的公开契约 | 边界 |
|---|---|---|
| 基础播放控制 | `play / pause / next / previous / seekTo` | 不能选择任意音轨或定义自有队列 |
| 曲库与当前歌曲 | 分页读取、按 ID 查询、当前媒体项查询 | 需要 LIBRARY_READ；当前歌曲查询阻塞等待数据库，应后台调用 |
| 进度与结束状态 | 每秒位置回调、`State.Ended` | 毫秒单位不等于毫秒采样精度；没有原子化音轨与位置快照 |
| 自定义歌词 | 前置与后备歌词字符串回调 | LRC / SPL 与双语显示有格式依据，实际文件兼容性需测试 |
| 指定音轨起播、队列读写 | **没有公开入口** | 第三方存在内部反射实现，不能当成官方保证 |
| 自定义主导航、作品页注册 | **没有稳定页面注册接口** | 内嵌依赖内部 UI 集成；独立窗口也需验证生命周期 |

`next()`、`previous()` 只操作宿主已有播放上下文，**不代表插件能控制整个 RJ 队列**。歌词加载回调也不是可靠的切轨事件。

## 第一阶段方案（待验证）

- **语言与构建**：Kotlin/JVM、Gradle、PF4J；参照 dev23 及宿主要求锁定工具链，生成 `.spmod`。
- **官方对接**：`SaltPlaybackAdapter` 封装查询、歌词、事件和基础控制。
- **内部对接**：`InternalPlaybackAdapter` 集中封装经验证的内部播放调用，可禁用、可识别版本；反射调用与字节码 Hook 分开描述。
- **数据**：P0 使用最小日志与状态文件；日用版采用本地 SQLite。自有作品、版本、音轨 ID 与 Salt ID 分开维护。
- **界面**：先用配置或快捷键驱动播放探针；通过后优先评估最小独立窗口，宿主导航嵌入后置。
- **规模**：先 3 部作品，分别测试已入库与未入库文件；不预设 Salt 曲库是播放前置条件，也不预设未入库文件可完整使用。

M3U8、命令行、系统打开方式仅为备选实验，尚未确认 Salt 的队列、起始轨或单实例投递行为。

## MVP 与退出条件

P0 必须证明：**完整本地队列、任意起始轨、自动与手动切轨、同一音轨的位置恢复**，并验证外部切歌、插件停用和不兼容版本时的行为。

通过后，首版只做少量目录导入、版本选择、排序、最小详情、完整作品续播及本地 LRC / SPL。历史、书签、搜索分类和大库优化按后续阶段推进。

若核心播放需要持续扩大的内部依赖，或出现无法消除的错轨、双跳、错误 seek，则暂停完整产品开发。伴侣模式仅是可选择的降级产品，不等于完成原始播放器需求。

## 数据与维护约束

- RJ 是外部编号，不单独作为所有副本、版本与音轨的主键；路径和局部哈希只用于匹配候选。
- 不把 Salt 歌曲 ID 当永久身份；官方不承诺曲库重建或跨设备后的稳定性。
- 扫描中断、断盘或权限失败不视为删除；保留人工修正、书签和进度。
- 保存采用事务或原子替换、版本化迁移和备份；数据独立于插件安装目录，支持导出。
- 不复制闭源宿主实现；第三方代码先逐文件核对许可证。
- 与 Salt Player 官方团队无关联。
